# Student-Management-System
A desktop-based Student Management System built using Python, Tkinter, and SQLite. This project helps manage student records, results, attendance, and user authentication through an easy-to-use graphical interface. It provides efficient data storage, search, update, and management features for educational institutions.

 ##Features
Student Registration
Add / Update / Delete Student Records
Course Management
Result Management
Search Functionality
User Login System
Password Recovery
Database Integration using SQLite3
Interactive GUI with Tkinter
 
 ###Technologies Used
Python
Tkinter
SQLite3
Pillow (PIL) for image handling

#### Structure of project
``` bash
│
├── images/                 # Project images and icons
├── database.db             # SQLite database
├── login.py                # Login system
├── dashboard.py            # Main dashboard
├── student.py              # Student management module
├── course.py               # Course management module
├── result.py               # Result management module
├── report.py
```
##### Running the app 
``` bash
python dashboard.py
```
